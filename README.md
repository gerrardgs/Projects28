## 📊 Overview & Projects

This repository consolidates practical data analysis workflows and production-style dashboards built by completing two premier data analytics curricula:
1. **Luke Barousse — Power BI for Data Analytics**: Data Jobs Dashboards 1.0 & 2.0 based on real-world 2024 data analytics job postings.
2. **Data With Baraa — Tableau Ultimate Course**: Enterprise HR Analytics Dashboard and Multi-Regional Sales & Customer Dashboards.

### 1. Power BI Core Workflows (`da/PowerBI/`)
- **Data Jobs Dashboard 1.0 & 2.0**: End-to-end report analyzing median salaries, top demanded skills, remote work distributions, and skill trends by job title.
- **Data Modeling & Star Schema**: Built dimension and fact tables (`company_dim`, `skills_dim`, `skills_job_dim`, `job_postings_fact`) connected with 1-to-many single-direction relationships.
- **Power Query (M) ETL**: Data cleaning, handling nulls, column transformations, unpivoting data, conditional columns, monthly file appending, and dimensional merging.
- **DAX Calculations**: Explicit measures including dynamic median salaries, distinct counts, time intelligence, parameters, and interactive filter measures.
- **Google BigQuery Integration**: Direct cloud connection and query execution importing large-scale data engineering and analytics postings into Power BI models.

### 2. Tableau Core Workflows (`da/TABLEAU/`)
- **HR Analytics Dashboard**: Employee retention, termination analysis, department demographics, performance tiers, and salary distribution.
- **Sales & Customer Dashboards**: EU and Non-EU multi-market order tracking, revenue velocity, customer segmentation, and geographical map layers.
- **Advanced Visualizations & Calculations**: Level of Detail (LOD) expressions, parameter actions, dynamic sorting, container-based dashboard UI layout, and custom UI icon assets.
